# Next Word Predictor
## Description
  A deep learning-based Next Word Predictor built using LSTM(Long Short-Term Memory) neural network.The model is trained on a quote dataset and learns patterns between words to generate meaningful text.

## Working
  1. Input text
  2. Tokenization
  3. Top-3 Predictions
  4. Word generation
  5. Full Quote Generation

## Live Demo
    https://next-word-predictor-oml7.onrender.com


## Tech stack
  * Python
  * Tensorflow
  * Keras
  * Numpy
  * Pandas

## Features
  * Modern UI
  * Custom Input and buttons
  * Generate Full Quote
  * Adjustable word count(up to 20)
  * Top-3 Prediction Probabilities

## Project Goals
  * Understand NLP preprocessing
  * Learn how tokenization works
  * Convert text into sequences
  * Understand word prediction
  * Implement an LSTM neural network
  * Generate text using a trained model
  * Understand how recurrent models process sequential data
## Conclusion
  This project demonstrates how an LSTM neural network can learn patterns from text and use those patterns to predict the next word and generate
  a sequence of words.
  By allowing the user to choose the number of words to generate,the project provides a simple way to experiment with AI-based text generation and NLP.
